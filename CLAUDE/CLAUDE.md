# Projet : Guess The Country
Jeu de quiz géographique React + Vite + TypeScript, destiné au Play Store (via TWA).

## Règles de travail
- Suivre ROADMAP.md dans l'ordre, cocher les cases au fur et à mesure
- Travailler sur une branche par phase (ex: phase-1-bugs), commits petits et clairs
- Vérifier que `npm run build` passe avant chaque commit
- Ne JAMAIS committer le build dans les sources
- Réponses et messages en français
- À la fin d'une phase : pousser la branche, résumer ce qui a été fait et ce qui reste
